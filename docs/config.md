# Configuration Specification

Модуль конфигурации отвечает за строгую валидацию переменных окружения при старте приложения с использованием `class-validator` и `class-transformer`.

## 1. Схема переменных окружения (`src/config/env.validation.ts`)

### Enum `Environment`
- `development` — Локальная среда разработки.
- `production` — Прод-окружение.
- `test` — Тестовое окружение для e2e и unit-тестов.
- `provision` — Окружение подготовки/сидирования.

### Класс `EnvironmentVariables`

| Переменная | Тип | Обязательность | Значение по умолчанию | Описание |
|---|---|---|---|---|
| `NODE_ENV` | `Environment` enum | **Обязательно** | — | Режим работы приложения (`development`, `production`, `test`, `provision`). |
| `PORT` | `number` | Опционально | `3000` | Порт HTTP-сервера. |
| `DB_HOST` | `string` | **Обязательно** | — | Хост PostgreSQL. |
| `DB_PORT` | `number` | Опционально | `5432` | Порт подключения к PostgreSQL. |
| `DB_USERNAME` | `string` | **Обязательно** | — | Пользователь базы данных. |
| `DB_PASSWORD` | `string` | **Обязательно** | — | Пароль базы данных. |
| `DB_DATABASE` | `string` | **Обязательно** | — | Имя базы данных PostgreSQL. |
| `DB_SYNCHRONIZE`| `boolean` | Опционально | `isDev` | Флаг автосинхронизации схемы TypeORM (по умолчанию включён в `development`). |
| `CORS_ORIGIN` | `string` | Опционально | `*` / все | Разрешённые CORS-источники (строка, список через запятую или `*`). |
| `SWAGGER_ENABLED` | `boolean` | Опционально | `true` | Включение генерации документации Swagger по пути `/api/docs`. |

## 2. Поведение валидации (`validate(config)`)

Функция `validate()` вызывается в `ConfigModule.forRoot({ validate })`:
- Преобразует строковые переменные `process.env` в типизированные примитивы (числа, булевы флаги, enum).
- При обнаружении пропущенных обязательных переменных или несовпадении типов выбрасывает критическую ошибку `Error` со списком нарушений, блокируя старт некорректно сконфигурированного сервиса.

## 3. Файлы окружения
Приложение загружает `.env` файлы в следующем порядке приоритета:
1. `.env.${NODE_ENV}.local`
2. `.env.${NODE_ENV}`
3. `.env`
