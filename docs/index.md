# Документация и спецификация Shelf API

`shelf-api` — RESTful сервис складского учёта и каталогизации электронных компонентов с динамической системой характеристик (EAV + JSONB-снимки), строгим контролем складских движений и встроенной поддержкой Model Context Protocol (MCP) для AI-агентов.

## 🧭 Каталог документации модулей

| Модуль | Файл спецификации | Описание |
|---|---|---|
| **Ядро и Bootstrap** | [docs/app.md](app.md) | Инициализация NestJS, конфигурация Helmet, CORS, ValidationPipe, версионирование `/api/v1`, Swagger UI и TypeORM. |
| **Базовая инфраструктура** | [docs/common.md](common.md) | Базовая сущность `AbstractBaseEntity`, DTO пагинации, глобальный `TypeOrmExceptionFilter` и доменные исключения. |
| **Конфигурация окружения** | [docs/config.md](config.md) | Строгая валидация `.env` переменных через `class-validator` и `EnvironmentVariables`. |
| **Health & Monitoring** | [docs/health.md](health.md) | Мониторинг сервиса: эндпоинты `/health`, Liveness `/health/live` и Readiness `/health/ready` пробы. |
| **Акторы и пользователи** | [docs/actors.md](actors.md) | Учет и атомарный UPSERT внешних идентификаторов пользователей (`actors`) для аудита складских операций. |
| **Единицы измерения** | [docs/units.md](units.md) | Справочник физических единиц измерения компонентов по группам (длина, масса, электрические величины и др.). |
| **Категории** | [docs/categories.md](categories.md) | Иерархическое дерево категорий неограниченной вложенности, хлебные крошки, защита от циклов. |
| **Теги** | [docs/tags.md](tags.md) | Цветовые метки и теги для гибкой классификации электронных компонентов. |
| **Динамические атрибуты** | [docs/attributes.md](attributes.md) | EAV-система характеристик, справочники опций (`select`/`multiselect`), движок валидации типов и аудит истории изменений. |
| **Компоненты (Детали)** | [docs/parts.md](parts.md) | Каталог деталей, JSONB-снимки характеристик, составная карточка компонента, фильтрация по параметрам и тегам. |
| **Складские движения** | [docs/stock.md](stock.md) | Приход, списание, корректировка и перемещение остатков с пессимистической блокировкой и защитой от отрицательных остатков. |
| **Административный дашборд** | [docs/admin.md](admin.md) | Агрегированная статистика по складу, критические остатки и последние движения (`/admin/stats`). |
| **Model Context Protocol (MCP)** | [docs/mcp.md](mcp.md) | MCP-сервер для AI-агентов: исследование OpenAPI, JSON-RPC 2.0, SSE, автоматическая генерация TypeScript-схем. |

## 📌 Правила актуализации документации

При внесении любых изменений в контроллеры, сервисы, DTO, сущности TypeORM или бизнес-логику модулей:
1. **Обязательно** обновите соответствующий файл в каталоге `docs/<module>.md`.
2. Если добавляется новый модуль или глобальный сервис — создайте `docs/<module>.md` и зарегистрируйте его в таблице `docs/index.md`.
3. Поддерживайте актуальность сигнатур DTO, схем ответов и возможных HTTP-кодов ошибок.
